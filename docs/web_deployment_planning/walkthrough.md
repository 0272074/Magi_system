# Web公開・マルチユーザー化機能の実装完了

ご指定の要件（APIキーのユーザー設定化、Google SSO認証、チャット履歴保存）を実装しました！

## 1. ユーザー独自のAPIキー利用 (BYOK)
サーバーの環境変数（`.env`）への依存を減らし、各ユーザーがブラウザ上でAPIキーを設定できる機能を追加しました。
- 画面右上の「⚙️設定」ボタンから、Gemini / Groq / OpenRouterの各APIキーを入力できます。
- 入力されたキーはブラウザの `localStorage` にのみ保存され、バックエンドサーバーには保存されないため安全です。

## 2. Google SSO認証 と 履歴表示 (Supabase)
フロントエンドから直接Supabaseと連携し、ログインと履歴の管理を行うアーキテクチャを採用しました。
これによりバックエンド（FastAPI）にDB管理の複雑さを持ち込むことなく、高速なレスポンスを実現しています。

- **ログイン**: 画面右上の「ログイン」ボタンから、Googleアカウントを用いたSSOログインが可能です。
- **履歴保存**: 合議が完了するたびに、質問内容や各AIの回答、最終決断がSupabaseのデータベースに自動保存されます。
- **履歴表示**: ログイン中は画面左側にサイドバーが表示され、過去のチャット履歴一覧を確認・復元できます。
