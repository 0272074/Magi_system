# Web検証機能の削除完了

Web事後検証プロセスにおいて、APIキーのクォータ制限（429エラー等）によるエラーや遅延が頻出するため、計画通りWeb検証（ファクトチェック）機能を白紙に戻しました。

## 変更内容
1. **バックエンド (`main.py`)**
   - `web_verification` モジュールのインポートと依存関係を削除しました。
   - 議長AI (`generate_council_decision`) のプロンプトからWeb事実検証に関するルールと入力を除去しました。
   - SSE通信からWeb検証関連のイベントを削除しました。
2. **モジュールの削除 (`web_verification.py`)**
   - 不要になったモジュールファイルを削除しました。
3. **フロントエンド (`index.html`, `script.js`)**
   - UIからWeb検証セクションおよびプロセス進行ステップを削除しました。
   - 不要になったWeb検証結果描画用のJS関数やイベントリスナーを撤去しました。

> [!TIP]
> サーバーを再起動しています。ブラウザで `http://127.0.0.1:8001/` にアクセスし、シンプルな3AI合議プロセスがスムーズに実行されるかお試しください！
